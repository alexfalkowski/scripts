# Accepted design

This index records the Scripts Toolbox's accepted design choices, tradeoffs,
and support boundaries. The area files carry the same weight as
[AGENTS.md](../../AGENTS.md).

Read the relevant area files before proposing a change or recording a finding
or audit entry. Revisit a decision when the owner asks or new evidence changes
its documented contract or tradeoff. Record new owner-accepted decisions in the
relevant area file.

- [CLI](accepted-design/cli.md) covers command dispatch, help, and shell completion.
- [Repository maintenance](accepted-design/repository-maintenance.md) covers
  repository sets, update and PR workflows, Bundler, CircleCI, and local tools.
- [AI sessions](accepted-design/ai-sessions.md) covers launcher configuration,
  skill metadata, and ledger ownership.
